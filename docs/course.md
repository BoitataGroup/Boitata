## Course  

<a href="https://learn.mit.edu/video-playlist/9277/mit-6-0002-introduction-to-computational-thinking-and-data">MIT 6.0002 Introduction to Computational Thinking and Data Science, Fall 2016</a>
<h3><strong>Description:</strong> MIT 6.0002 (Introduction to Computational Thinking and Data Science) is a foundational course designed to teach students how to use computation to solve real-world problems. It serves as a direct continuation of MIT 6.0001 (Introduction to Computer Science and Programming in Python) and focuses on using Python to analyze, visualize, and model data. <span></span></h3>

<a href="https://deeplearningwithpython.io/chapters/">Deep Learning with Python</a>
<h3><strong>Description:</strong> Deep Learning with Python by François Chollet is a definitive, hands-on textbook that teaches modern artificial intelligence using the Python language and the Keras/TensorFlow ecosystem. Rather than drowning the reader in heavy mathematical proofs, it relies on code snippets, visual intuition, and practical engineering habits to explain concepts. <span></span></h3>
